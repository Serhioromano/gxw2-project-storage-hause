# Проект ПЛК — автоматизация камеры овощехранилища (COOLMAY-L02 / GX Works 2)

Один проект заливается в 10 однотипных шкафов **ШУК.260726** (10 камер).
Отличия между камерами (если появятся) выносятся в настройки HMI.

Источники истины:
- план разработки: `plnas/план_разработки.md` (этапы, POUs, карта регистров);
- ТЗ v1.1: `Ссылки/тз_финальное.md`;
- карта адресов: `Ссылки/плк.txt`, привязка меток — `ПЛК/IO.csv`;
- библиотеки: `Ссылки/AlarmManagerV203.md`, `Ссылки/Modbus.EN.md`, `Ссылки/UtilsV3.md`.

## 1. Структура файлов

| Файл | POU / назначение |
|---|---|
| `ПЛК/IO.csv` | Глобальные метки I/O (X/Y/AI) — импортировать первым (уже в репозитории) |
| `ПЛК/GVL.csv` | Глобальные переменные: настройки (D100–D123), статусы (D200–D222), упаковка тревог (D300–D301), команды (M20–M71) |
| `ПЛК/src/main.st` + `main.csv` | **MAIN** — программа; вызывает ФБ в порядке INIT→IO→ALARMS→MODE→PROCESS→ACTUATORS→HMI |
| `ПЛК/src/init.st` + `init.csv` | **INIT** (FB) — настройки по умолчанию, AM_INIT (28 тревог), L02_SET_IP, (задел) Modbus |
| `ПЛК/src/io.st` + `io.csv` | **IO** (FB) — SCALE_AI (host: улица Pt100, t°/влажн. ПВТ110 4-20 мА), L02_SCALE_AI (4 щупа), средняя t продукта |
| `ПЛК/src/alarms.st` + `alarms.csv` | **ALARMS** (FB) — AM_SET ×28, AM_HAS_ALARM / AM_IS_BLOCK, AM_PACK (D300–D301), ручной сброс + автосброс |
| `ПЛК/src/mode.st` + `mode.csv` | **MODE** (FB) — выбор режима по переключателю, световая колонна (M8013 — мигание) |
| `ПЛК/src/process.st` + `process.csv` | **PROCESS** (FB) — автомат Авто (0/100/200/300/400), регулярная и ручная аспирация |
| `ПЛК/src/actuators.st` + `actuators.csv` | **ACTUATORS** (FB) — выходы: вентиляторы, клапаны, подогрев, Y00; синхронизация с X20 в рециркуляции |
| `ПЛК/src/hmi.st` + `hmi.csv` | **HMI** (FB) — статусы и битовые слова для TK8100 (D211–D218) |

Формат CSV — **UTF-16 LE с BOM**, таб-разделитель, все поля в кавычках
(формат экспорта GX Works 2 Label Editor). `.st` — код без `VAR...END_VAR`
(переменные — только в CSV).

## 2. Сборка проекта в GX Works 2 (порядок)

1. **Новый проект**: серия FX3G/FX3U (COOLMAY-L02, совместим с FX3G), язык IEC.
2. **Настройки проекта → устройства (Device allocation)** — увеличить лимиты
   автоматически назначаемых устройств (требование AlarmManager V203):
   - D-регистры: **+1400**;
   - M-регистры: **+2000**.
3. **Установить библиотеки** (менеджер библиотек):
   TimeControl V2, AlarmManager V203, Modbus V1.5, Utils V3.
4. **TimeControl V2** — настроить тикер **TCO_TICKER_50** (50 мс). Строку вызова
   в `main.st` сверить с сигнатурой установленной библиотеки
   (в проекте используется вызов как функции `TCO_TICKER_50();`).
5. **Label Editor → Import**: `IO.csv` (глобальные метки I/O), затем `GVL.csv`
   (глобальные переменные).
6. **Создать POUs**:
   - `MAIN` — тип Program;
   - `INIT`, `IO`, `ALARMS`, `MODE`, `PROCESS`, `ACTUATORS`, `HMI` — тип Function Block.
7. Для каждого POU: **Label Editor → Import** соответствующий `src/<pou>.csv`,
   затем вставить тело из `src/<pou>.st` в редактор ST.
8. Скомпилировать (F4). Проверить: `AM_ALARMS_NUM = 28`, ошибок связывания нет.

> **ВАЖНО про `src/io.csv`**: это файл локальных переменных ФБ **IO**
> (7 колонок). Он не конфликтует с глобальным `ПЛК/IO.csv` (11 колонок,
> метки I/O) — импортируются в разные места проекта.

## 4. Тревоги (28, AlarmManager V203)

| ID | Тревога | Задержка | Защёлка | Severity |
|---|---|---|---|---|
| 0 | Реле контроля фаз (X02) | 0 с | нет | Error, xLock |
| 1–6 | Клапан не открылся | 60 с | нет | Warning |
| 7–12 | Нет потока, напорный вент. | 30 с | нет | Error |
| 13–18 | Пускатель напорного не замкнулся | 3 с | **да** (ручной сброс) | Error |
| 19–22 | Обрыв Pt100 щуп 1–4 | 3 с | нет | Warning |
| 23 | Обрыв Pt100 улица | 3 с | нет | Warning |
| 24–25 | Обрыв 4-20 мА ПВТ110 | 3 с | нет | Warning |
| 26 | t продукта выше макс. | 5 с | нет | Error |
| 27 | Влажность ниже мин. | 5 с | нет | Error |

Защёлки (13–18) снимаются кнопкой сброса на экране тревог HMI (M63).
Автосброс (всех, включая защёлки) — по настройке `g_iAutoReset` (по умолчанию
выключен) через `g_iAutoResetDelay` минут.

## 5. Примечания и проверки при сборке/пуске

1. **TCO_TICKER_50** — единственное место, где сигнатура зависит от
   установленной версии TimeControl V2. Проверить на этапе сборки.
2. **Полярности входов** (концевики клапанов, РД-ДД200 — контакт НЗ) приняты:
   «не открыт»/«нет потока» = вход **1**. Подтвердить электриками при пуске.
3. **M8013/M8014** — тактовые генераторы 1 с / 1 мин. На COOLMAY-L02
   (FX3G-совместимый) присутствуют; при отсутствии M8014 заменить тик
   рециркуляции на TON 60 с.
4. **IP-адреса ПЛК** задаются с HMI (D120–D123) и применяются кнопкой
   «Применить IP» (M64) или при включении.
5. **Modbus** для диспетчеризации/PUSH — задел, отключён (комментарий в `init.st`).
6. Значения температуры — в **°C×10** (например, 245 = 24.5 °C), влажность —
   в **%×10** (например, 850 = 85.0 %).
