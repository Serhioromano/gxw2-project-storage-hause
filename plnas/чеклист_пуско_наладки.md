## 2. Аналоговые входы (IO)

- [ ] D0–D1 (t улицы, REAL ×10) соответствует эталонному термометру (±0.5 °C)
- [ ] D2–D3 (t камеры ПВТ110, REAL ×10) соответствует эталону в диапазоне −40…+80 °C
- [ ] D4–D5 (влажность ПВТ110, REAL ×10) соответствует эталону в диапазоне 5…95 %
- [ ] D6–D13 (щупы 1–4, REAL ×10) соответствуют эталону; щуп в кипятке/тающем льду — корректно
- [ ] D14–D15 (средняя t, REAL) = среднему арифметическому D6–D13
- [ ] Обрыв щупа → тревога 19–22 через 3 с (значение ≤ −1900) — проверить фактическое значение модуля L02-RTD
- [ ] Обрыв улицы → тревога 23 через 3 с
- [ ] Обрыв 4-20 мА (t°/влажн.) → тревоги 24–25 через 3 с (ErrWire SCALE_AI)

## 3. Дискретные входы и полярности

- [ ] X00/X01 — переключатель режимов отображается в D222 (0/1/3)
- [ ] X02 — имитация ошибки фазировки: тревога 0 мгновенно, все вентиляторы стоп
- [ ] X06–X13 — ОС напорных вентиляторов: при команде без ОС → тревога 13–18 через 3 с (защёлка), сброс — кнопкой
- [ ] X24–X31 — концевики клапанов: подтверждена полярность (НЗ: открыт = 0)
- [ ] X32–X37 — РД-ДД200: подтверждена полярность (НЗ: поток = 0)
- [ ] X20/X21 — охладитель и увлажнитель: HMI отображает по прямым входам X20/X21

## 4. Выходы и приводы

- [ ] Y02–Y05 — разгонные вентиляторы включаются в аспирации и по X20 в рециркуляции
- [ ] Y06–Y13 — напорные вентиляторы: то же
- [ ] Y20–Y23 — подогрев заслонок: включается при t улицы < порога на время предподогрева
- [ ] Y24–Y31 — клапаны Belimo: открываются по команде, закрываются пружиной при снятии
- [ ] Y00 — при аспирации = 1 (запрет холода), в остальных режимах = 0
- [ ] Y32/Y33 — световая колонна по таблице §6.7 плана

## 5. Режимы (PRG_MAIN — автомат)

- [ ] Выключено: все DO = 0, Y00 = 0, колонна off
- [ ] Продувка: рециркуляция открыта, приток/сброс закрыты, вентиляторы — вручную, колонна 🔴+🟢
- [ ] Авто → рециркуляция: рециркуляция открыта; охладитель вкл (X20) → все 10 вент. вкл; X20=0 → стоп
- [ ] Авто → аспирация по таймеру: после 600 мин (или ускоренный тест) — проверка t улицы, пропуск при t вне 3…25 °C
- [ ] Аспирация: Y00=1, приток/сброс открыты, рециркуляция закрыта, пауза 30 с, затем все 10 вент. вкл, 5 мин
- [ ] Подогрев заслонок при t улицы < 5 °C на время предподогрева
- [ ] Завершение: приток/сброс закрыты, рециркуляция открыта, Y00=0, возврат в рециркуляцию
- [ ] Ручная аспирация (M522 + D506) из Авто: прерывает цикл, отрабатывает заданное время, возврат в рециркуляцию
- [ ] Ручная аспирация из Выключено/Продувки: отрабатывает и возвращает в предыдущий режим
- [ ] Переключение режима во время аспирации: автомат уходит в IDLE
